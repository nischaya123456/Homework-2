เกี่ยวกับการเรียน Full Stack Web Development

เหตุผลที่อยากเรียน Full Stack Web Development

ปัจจุบันแทบทุกธุรกิจต้องมีเว็บไซต์หรือแอปพลิเคชันเป็นของตัวเอง วาวาจึงอยากมีทักษะที่สามารถสร้างระบบได้ครบตั้งแต่หน้าจอที่ผู้ใช้เห็นไปจนถึงระบบหลังบ้านและฐานข้อมูล การเป็น Full Stack Developer ทำให้ทำงานได้หลากหลาย เข้าใจภาพรวมของระบบ และสามารถสร้างโปรเจกต์ของตัวเองได้โดยไม่ต้องพึ่งคนอื่นในทุกขั้นตอน

ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้เรียนรู้พื้นฐาน HTML, CSS, JavaScript และการเชื่อมต่อกับ Server และฐานข้อมูลอย่างเป็นขั้นตอน ได้ลงมือปฏิบัติจริงจนสามารถสร้างเว็บแอปพลิเคชันที่ใช้งานได้ 1 ชิ้น และนำขึ้นออนไลน์เพื่อใส่ในผลงาน (Portfolio) ได้

จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

จุดอ่อนของวาวาคือยังขาดความมั่นใจในการเขียนโค้ดด้วยตัวเอง มักต้องเปิดตัวอย่างดูก่อนเสมอ และยังแก้ไขข้อผิดพลาด (debug) ได้ไม่คล่อง แนวทางพัฒนาคือ ฝึกเขียนโค้ดทุกวันอย่างน้อยวันละ 30 นาที ทำโปรเจกต์เล็ก ๆ ต่อเนื่อง อ่าน Documentation และฝึกอ่าน error message อย่างตั้งใจ รวมถึงใช้ Git/GitHub เก็บงานเพื่อดูพัฒนาการของตัวเอง
